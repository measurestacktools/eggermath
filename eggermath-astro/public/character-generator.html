A seed only steers the random rolls, so the same words always produce the same character.

    Pasting your Perchance lists

    Perchance generators are lists plus a template. Two constructs carry almost all of the work, and both are supported here: 

    // Perchance
firstName = {Aria|Bram|Cleo|Dara}
className = {Scholar|Ranger|Healer}
backstory = {[firstName] grew up in [hometown], where the [season] fair never ended.|…}

// This file (same data, JavaScript arrays)
const LISTS = {
  firstName: L('Aria|Bram|Cleo|Dara'),
  className: L('Scholar|Ranger|Healer'),
  backstory: [
    '[firstName] grew up in [hometown], where the [season] fair never ended.',
  ],
};
    • {a|b|c} picks one option at random. Put it in a string and it expands.
    • [listName] pulls a random entry from another list, then expands that too.
    • {common^4|rare} weights an option; ^4 makes it four times as likely.
    • L('…') is a helper that turns a pasted {a|b} body into an array.

    Keep the braces out of L() — pass the inside. Unknown references are skipped and logged to the console, so a typo never produces a half-empty card silently.
